# CT Model Defense Traces

This directory is the local evidence area for the CT metal artifact model.

## Contents

- `xunlian/`: original six experiment archives and extracted experiment folders.
- `python-ml-data/`: restored CT/MASK DICOM dataset used for training.
- `python-ml-docs/`: CT model experiment plans, result summaries, and demo
  checklists moved out of the backend code tree.
- `CT影像AI模块工作路线与留痕清单.md`: high-level workflow and defense checklist.

Large files in this directory are kept locally and ignored by Git. Commit only
small summary documents or indexes that help teammates understand where the
evidence lives.
