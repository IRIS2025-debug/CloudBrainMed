# Restored Reference Materials

This folder holds materials restored for reference only. They are not part of
the CloudBrainMed runtime code path.

Typical contents include:

- `course/`: course examples and early exploration code.
- `teach/`: teacher-provided model/reference entry points.
- `tmp_inspect_dataset_folder/`: temporary dataset inspection output.
- `temp_share.js`: temporary sharing/inspection helper.

Keep new experimental or reference-only files here instead of placing them under
`frontEnd/` or `backEnd/`.
